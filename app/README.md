# Laboratorio 01: Hola Mundo en Android Studio

**Estudiante:** Yoselin Fabiola Flores Quispe  
**Curso:** Programación en Móviles

## Descripción
Aplicación móvil desarrollada en Android Studio utilizando Kotlin y Jetpack Compose.
Incluye un saludo personalizado con los datos del estudiante, la información del curso y un botón interactivo que muestra un mensaje en pantalla al presionarse.

## Funcionalidades
- Saludo personalizado con Jetpack Compose.
- Interfaz reactiva utilizando variables de estado (`remember` y `mutableStateOf`).
- Botón interactivo que actualiza el texto en la UI.
